## Featured Engineering Projects

### 01. PortfolioPulse — Multi-Tenant Backend Application

A portfolio reporting application demonstrating organisation-scoped data, authentication, controlled submissions, and auditable business workflows.

**Engineering highlights**
- JWT authentication and role-based access control.
- PostgreSQL data modelling and tenant isolation.
- CSV ingestion with validation and actionable feedback.
- Submission review, approval, and resubmission workflows.
- Database migrations and automated tests.

**Stack:** Python · FastAPI · PostgreSQL · SQLAlchemy · Alembic · Pytest

[View Repository](https://github.com/faraz-369/portfoliopulse)

### 02. AgentFault Lab — Agent Workflow Reliability

A controlled environment for studying failure and recovery behaviour in multi-step agent workflows.

**Engineering highlights**
- Controlled fault injection: timeouts, malformed responses, and exceptions.
- Structured execution traces.
- Explicit invariant checking.
- Comparison of no-recovery, retry, and state-aware recovery policies.
- API, CLI, SQLite persistence, and automated tests.

**Stack:** Python · FastAPI · SQLite · Pytest · Docker

[Repository](https://github.com/faraz-369/agentfault-lab-Web) · [Live Demo](https://agentfault-lab-web.vercel.app/) · [Methodology](https://github.com/faraz-369/agentfault-lab-Web/blob/main/docs/benchmark-methodology.md)

### 03. RAG Agent Failure Catalog

A reproducible catalogue of failure patterns in retrieval-augmented generation and agent workflows, with minimal examples, detection strategies, and mitigation ideas.

**Stack:** Python · RAG · FAISS · Testing

[View Repository](https://github.com/faraz-369/rag-agent-failure-catalog)

### 04. Data Quality Pipeline

An interactive data processing application for inspecting datasets, identifying quality issues, and detecting potential anomalies.

**Engineering highlights**
- CSV ingestion and validation.
- Missing-value and duplicate analysis.
- Statistical anomaly detection.
- Risk classification and downloadable reports.

**Stack:** Python · Pandas · Scikit-learn · Gradio

[Repository](https://github.com/faraz-369/data-quality-pipeline) · [Live Demo](https://huggingface.co/spaces/Faraz618/data-quality-pipeline)
