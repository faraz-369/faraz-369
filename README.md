## Selected Engineering Projects

### 1. AgentFault Lab — Backend Systems & Reliability Engineering

**Python · FastAPI · SQLite · Pydantic · Docker · Next.js**

An open-source engineering prototype for reproducing failures and evaluating recovery behaviour in multi-step agent workflows.

The project explores how software systems can detect failures, record execution behaviour and evaluate recovery strategies against explicitly defined invariants.

**Engineering implementation**

- Modular Python application architecture.
- FastAPI endpoints and command-line execution tools.
- Pydantic-based request and data validation.
- SQLite persistence and structured experiment records.
- Controlled failure simulation, including timeouts, exceptions and malformed responses.
- Retry and state-aware recovery policies.
- Unit, API, integration and regression tests.
- Docker and Docker Compose.
- GitHub Actions.

**Evaluation and reproducibility**

The repository documents a 45-run baseline across three scenarios and three recovery policies. Experiments use deterministic simulated tools. Results evaluate the controlled experiment harness, not production-wide AI-agent reliability.

**Project status:** Working research and engineering prototype.

**Explore the project:**

- [GitHub Repository](https://github.com/faraz-369/agentfault-lab-Web)
- [Live Project Interface](https://agentfault-lab-web.vercel.app/)
- [Benchmark Methodology](https://github.com/faraz-369/agentfault-lab-Web/blob/main/docs/benchmark-methodology.md)
- [Experiment Results](https://github.com/faraz-369/agentfault-lab-Web/tree/main/results)

## Engineering Principles

- **Understand the problem:** Translate business requirements into clear technical requirements.
- **Design deliberately:** Choose appropriate architecture, interfaces and data models.
- **Protect data integrity:** Prioritise validation, consistency and predictable data transformations.
- **Design for failure:** Account for errors, timeouts and unreliable dependencies.
- **Verify behaviour:** Use reproducible tests and observable evidence.
- **Build for maintainability:** Write understandable code and document important decisions.
- **Use AI responsibly:** Treat generated code as something to review, test and understand.
