## Engineering Principles

**Build around real problems.** Understand the user and the problem before choosing a technology or architecture.

**Design clear application boundaries.** Keep APIs, business logic, persistence, and integrations understandable and maintainable.

**Treat data carefully.** Reliable software depends on sound data models, validation, consistency, and predictable processing.

**Engineer for failure.** Consider error handling, retries, system state, and recovery behaviour rather than assuming every operation succeeds.

**Test actual behaviour.** Features should be verified through meaningful tests and reproducible scenarios.

**Document technical decisions.** Architecture, assumptions, limitations, and trade-offs should be clear to other engineers.

**Improve through implementation.** I value building, testing, learning, and refining working software.
